# 迭代规划（roadmap.md）

## 已完成（v1.0）

- 五个角色的 JWT 登录注册与权限字段
- 项目 / 分集 / 剧本多版本 / 场次 / 分镜（排序、重排）/ 角色卡 / 场景卡
- 提示词构建器（7 段公式）与 12 套画风模板、提示词历史
- AIGC 生成任务（文生图 / 图生视频）+ 线程池执行 + 排队/生成中/成功/失败/超时 + 轮询 + 取消 + 重试
- 三种生成服务：离线 `mock`（默认可跑）、ComfyUI、OpenAI 兼容图像接口
- 素材库：分类筛选、评分、入选/淘汰、批量操作、二次优化（问题标注 → 追加修正词 → 重绘 → 链路留痕）
- 成片合成单：镜头清单、字幕、转场、自动填充、质检清单、CSV/JSON/SRT/ZIP 导出与导出历史
- 审核流：提交 / 通过 / 驳回（带意见）/ 留痕
- 数据看板：成功率、平均耗时、素材统计、项目进度、7 日趋势
- 42 个 pytest 用例、统一响应体与异常、`X-Request-Id` 链路

## 已知限制

1. `mock` provider 生成的是占位插画（渐变/光斑/剪影/信息带），不是真正的动漫画面；真实画面需接 ComfyUI 或云端模型。
2. 图生视频（`img2video`）当前走同一套 mock 流程，产出单帧动画占位图，不生成视频文件；真实视频生成依赖 v2.0 的 ffmpeg + 视频工作流。
3. 未内置 ffmpeg 串片，成片以「合成单 + 导出文件」交付给剪辑环节。
4. 单进程线程池，重启会中断运行中的任务（重启后标记为 failed，可一键重试）。
5. 无多租户隔离，所有登录用户共享同一批项目数据（角色字段尚未用于细粒度数据权限）。
